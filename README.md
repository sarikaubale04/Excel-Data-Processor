
# Excel Data Processor

A Python project that processes Excel files, detects missing values, identifies duplicate records, and creates a cleaned Excel file.

## Features
- Reads Excel files using openpyxl
- Counts student records
- Detects missing marks
- Identifies duplicate records
- Removes duplicate records from the cleaned sheet
- Saves cleaned data into a new Excel file

## Technologies Used
- Python
- openpyxl

## How to Run
1. Install openpyxl:
   pip install openpyxl
2. Place students.xlsx in the project folder.
3. Run:
   python main.py

## Output
The program generates a file named cleaned_students.xlsx containing unique student records.

## Purpose
Built as a beginner Python automation and data-processing project.
